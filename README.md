## Project Overview

This project investigates how read length affects the quality of DNA sequence embeddings generated by DNABERT-S. Specifically, we examine whether the model can better distinguish sequences from different species in embedding space when using long reads versus short reads.

### Research Question
Does read length (short vs. long) impact species separation in DNABERT-S embeddings?

### Main Objectives
1. Set up DNABERT-S on LiSC HPC system
2. Generate synthetic metagenomic datasets (short and long reads)
3. Compute embeddings using DNABERT-S
4. Explore embeddings using clustering and dimensionality reduction
5. Assess species separation quality

## Coverage Calculation

For 10x coverage of our metagenomic community:
- **Short reads (150bp):** ~2.4 million reads
- **Long reads (10kb):** ~36,000 reads

Coverage formula:
```
Number of reads = (Coverage × Genome size × Abundance) / Read length
```
